User requested implementation plan generation for Phase IV AI-Powered Todo Chatbot using `/sp.plan` command.

**Requirements**:
- Generate technical implementation plan
- Resolve all technical unknowns through research
- Design data model for conversation storage
- Define API contracts for chat endpoint and MCP tools
- Create developer quick start guide
- Validate against constitution principles

## Response snapshot

**Phase 0: Research & Technical Decisions** (research.md)

Resolved 8 technical unknowns:

1. **OpenAI Agents SDK Integration**: Service layer pattern with dependency injection, agent instance per request
2. **MCP Server Structure**: Separate module architecture (server.py, tools.py, handlers.py) delegating to existing TaskService
3. **OpenAI ChatKit Frontend**: Standard integration with domain allowlist configuration post-deployment
4. **Stateless Architecture**: Paginated conversation history (last 50 messages), database-backed state
5. **Natural Language Intent**: Explicit instruction prompts with command examples and error handling
6. **OpenAI API Errors**: Retry with exponential backoff (3 attempts), 30s timeout, graceful degradation
7. **Conversation Archival**: 90-day soft delete with archived_at timestamp
8. **Authentication Integration**: Reuse existing Phase III JWT system with get_current_user dependency

**Phase 1: Design & Contracts** (data-model.md, contracts/)

**Data Model**:
- **Conversation** entity: id, user_id, created_at, updated_at, archived_at
- **Message** entity: id, conversation_id, user_id, role (user/assistant), content, created_at
- Indexes on conversation_id, user_id, archived_at for performance
- Migration scripts for PostgreSQL table creation

**API Contracts**:
- **Chat Endpoint**: POST /api/{user_id}/chat with conversation_id (optional) and message
- **Response**: conversation_id, response text, tool_calls array
- **MCP Tools** (5 tools): add_task, list_tasks, complete_task, delete_task, update_task
- Full OpenAPI 3.0 spec and MCP JSON schema definitions

**Quick Start Guide** (quickstart.md):
- Backend setup (Python 3.13+, FastAPI, OpenAI SDK, MCP SDK)
- Frontend setup (Next.js 14+, OpenAI ChatKit)
- Environment configuration (OpenAI API key, database URL, JWT secret)
- Testing instructions (manual API testing, automated tests)
- Deployment guide (Hugging Face + Vercel)
